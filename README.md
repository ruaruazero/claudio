<h1 align="center">Claudio</h1>

<p align="center">一个陪你听歌、工作和聊天的个人 AI 音乐电台。</p>

Claudio 的出发点是以前的深夜广播：有人选歌，也有人偶尔说说话。你可以告诉它现在想听什么、正在做什么，也可以聊一首歌带来的感受。音乐是陪伴的一部分，对话也是。

这是一个仍在迭代的个人项目。目前提供 **macOS Apple Silicon（M 系列芯片）** 桌面测试版；暂不支持 Intel Mac，Windows 版尚未发布。

## 可以做什么

- **听歌与选歌**：按歌名、歌手或当下的场景点歌，也可以让 Claudio 换一批、补充待播队列。
- **聊天式推荐**：推荐可以作为歌曲卡片出现在对话中，不必每次都改动正在播放的内容。
- **语音陪伴**：使用小米 MiMo 合成语音，支持自动播报回复、手动播报消息和主动串场；自动播报与串场可以分别关闭。
- **偏好与记忆**：结合交流、听歌反馈和导入记录积累个人偏好，在设置中查看 Claudio 对你的认识。这部分仍在打磨，推荐不一定每次都准确。
- **自然环境音**：混入雨声、海浪或炉火声，独立调整音量。
- **桌面体验**：提供日间与夜间主题、头像与称呼设置，并适应不同窗口尺寸。

## 开始使用

### 1. 安装

拿到 macOS ARM64 的 `.dmg` 安装包后，打开它，将 **Claudio** 拖入 **Applications（应用程序）**，再从应用程序中启动。

桌面版自带本地后端和音乐适配服务，普通使用无需安装 Node.js，也不需要另开终端启动服务。

当前安装包使用 ad-hoc 签名，尚未经过 Apple Developer ID 签名及公证，因此不受 Gatekeeper 自动信任。首次打开可能受到 macOS 安全提示限制。请只安装你信任来源的构建；如被阻止，可在系统的「隐私与安全性」中查看是否提供「仍要打开」。如果仍提示损坏或没有授权入口，请反馈系统版本和完整提示，不要关闭系统安全保护。

### 2. 配置对话和语音

点击右上角的设置按钮，进入 **模型与语音服务**：

| 服务 | 用途 | 当前默认模型 | 是否需要 |
| --- | --- | --- | --- |
| DeepSeek | 对话、选歌与工具决策 | `deepseek-flash` | 使用 AI 功能需要 |
| 小米 MiMo（限时免费） | 将回复转换成声音 | `mimo-v2.5-tts` | 需要语音时配置 |

分别切换到「对话模型」和「语音播报」，填写对应供应商的 API Key，点击 **保存并生效**。可以再点击 **验证服务** 确认配置是否可用。

API Key 需要从各供应商平台自行申请，调用费用由你的供应商账户承担。「验证服务」也会发起一次简短调用，可能产生少量费用。只想先体验文字交流，可以暂不配置 MiMo。

不要把 API Key 发进聊天框、截图或公开的 Issue。

### 3. 连接音乐账号

在 **设置 → 网易云音乐** 中，可以选择 **在网易官方页面登录**，也保留了扫码登录入口。

可播放范围受账号权限、会员状态、地区、版权及上游接口影响，登录不代表所有歌曲都能完整播放。在设置中可以选择是否允许播放试听片段。

如果网易提示「设备环境异常」或拦截登录，请按其提示处理，避免连续反复尝试；Claudio 无法保证第三方登录和音乐接口始终可用。

### 4. 开始你的电台

在聊天框里说出你想要的音乐或正在做的事，例如：

> 放点安静的歌，我要工作了。
>
> 听腻了，换一批吧。
>
> 给我推荐几首晚上干活的歌，先别换正在放的。
>
> 这首挺喜欢的，以后可以多来点这种。

直接使用播放控制器可以暂停、续播和切到下一首；展开「待播」可以查看队列。点击聊天中的歌曲卡片播放，会替换当前曲目，保留原有待播队列。

在 **设置 → 声音与陪伴** 中，可以分别调整自动播报回复、主动串场和试听片段。单条 Claudio 消息旁的播放按钮可以手动播报这条回复。

想让它更早了解你的听歌习惯，可以进入 **设置 → 导入歌单与听歌记录**，导入网易云歌单或账号可获取的听歌记录；在 **我的偏好与记忆** 中查看已形成的偏好。

## 桌面使用与数据

**关闭窗口不会完全退出应用。** 电台会保留运行，点击 Dock 图标可以重新打开；通过应用菜单或 `⌘Q` 完全退出。

后端运行在你的电脑上，仅监听本机地址。桌面数据保存在：

```text
~/Library/Application Support/Claudio/
```

对话、偏好和配置会持久化保存在本机。API Key 与音乐凭据通过 Electron `safeStorage` 使用系统能力加密保存。macOS 可能弹出钥匙串授权提示；目前未签名的测试版在更新后可能再次要求授权。

**本地运行不等于所有处理都在本地。** 对话、被选入上下文的记忆和相关状态会发送给对话模型供应商；需要播报的文字会发送给语音供应商；音乐搜索、登录及播放需要连接音乐服务。当前版本需要网络，不提供离线音乐库。

## 当前限制

- 推荐、记忆和主播的表达仍在迭代，AI 可能误解意图或给出不准确的信息。
- 网易云接入依赖第三方适配接口，不是网易官方客户端；接口变化、登录风控和音源失效都可能影响使用。
- 暂未完成签名、公证与广泛的外部用户安装测试，目前适合作为测试版体验。
- 日程系统、多用户及离线音乐不在当前版本范围内。

遇到问题时，可以在 **设置 → 运行记录** 查看相关信息。反馈时附上操作步骤、预期结果、实际结果和应用版本；提交记录或截图前，请移除个人对话、密钥和登录凭据。

## 本地开发

项目使用 React、TypeScript、Vite、Electron、Fastify、LangChain / LangGraph 和 SQLite。

需要 Node.js 22 或更新版本，以及 npm。在项目目录执行：

```sh
npm ci
cp .env.example .env
npm run server
```

另开一个终端：

```sh
npm run dev
```

打开 `http://127.0.0.1:5180/`。也可以启动后在设置中填写 API Key，无需把密钥写进 `.env`。

开发后端默认端口为 `8081`，内置网易适配接口默认端口为 `3000`。开发数据保存在 `.data/`，与桌面版数据隔离。配置项见 [`.env.example`](.env.example)。

### 检查与测试

```sh
npm run typecheck
npx tsx --test --test-concurrency=1 server/*.test.ts
npm run test:sequences
npm run build
```

以上检查使用模拟模型与本地数据，不消耗模型余额。`npm run test:behavior` 会调用真实模型并产生费用。

浏览器回归需要先启动 Vite 服务：

```sh
npx playwright install chromium
npx tsx scripts/test-browser-playback.ts
npx tsx scripts/test-browser-personalization.ts
```

浏览器脚本支持通过 `CHROME_EXECUTABLE_PATH` 指定已安装的 Chrome。

### 构建 macOS 安装包

在 Apple Silicon Mac 上执行：

```sh
npm ci
npm run desktop:mac
```

产物位于 `release/<版本号>/`，包括 ARM64 的 DMG 和 ZIP。构建过程使用独立的 `.desktop-stage/` 目录安装生产依赖、重建 Electron 所需的 SQLite 原生模块。

构建后可运行：

```sh
npm run test:desktop
```

桌面回归使用临时目录、测试凭据和隔离的测试配置，不读取真实账号，也不访问系统钥匙串。正式运行仍使用系统凭据加密。

### 代码结构

| 路径 | 职责 |
| --- | --- |
| `src/ui/` | 电台界面、聊天、队列与设置 |
| `src/useRadioController.tsx` | 前端状态、连接恢复及播放与播报协调 |
| `src/audio-engine.ts` | 音频分析与自然环境音 |
| `src/protocol.ts` | 前后端消息和状态协议 |
| `server/agent.ts`、`server/tools/` | Agent 执行与业务工具 |
| `server/knowledge.ts`、`server/profile.ts` | 长期记忆与结构化偏好 |
| `server/recommendation.ts` | 对话推荐与后台补歌 |
| `server/http.ts` | 本地接口、事件流和生命周期 |
| `server/music.ts`、`server/netease-service.ts` | 音乐服务适配 |
| `server/speech.ts` | MiMo 语音合成与流式播报 |
| `desktop/` | 桌面窗口、本地服务启动和系统凭据存储 |
| `scripts/` | 构建、测试与诊断 |

播放器按钮在前端直接执行，再异步同步状态；Agent 的播放命令通过命令与回执确认结果。桌面界面使用固定的 `app://claudio` 源，由主进程代理到本机随机端口的后端，并通过每次启动生成的私有令牌保护接口。
